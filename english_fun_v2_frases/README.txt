ENGLISH FUN – site infantil para aprender inglês

Como abrir: extraia o ZIP e dê dois cliques em index.html. Não precisa instalar nada.
Jogos: Traduza a palavra, Que figura é essa?, Caça-palavras, Jogo da memória e Monte a frase (22 frases para ordenar).
Contas: criar conta e entrar (guardadas só no navegador deste aparelho; não use senhas reais).
Os sons usam a voz do navegador (inglês). Para publicar, envie os 4 arquivos ao GitHub Pages.
Para adicionar palavras, edite a lista W no início de script.js: ["inglês","português","emoji"].
